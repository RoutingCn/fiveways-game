# 下五道 · Fiveways Game

一个可直接在浏览器运行的网页版下五道游戏。棋盘使用泥土地照片，双方棋子分别是木桩和石子，支持人机对战与本地双人对战。

## 运行

直接双击打开 `index.html` 即可游玩。

如果想通过本地服务访问，也可以在本目录运行：

```bash
npx serve .
```

然后打开：

```text
http://127.0.0.1:3000/
```

## 功能

- 人机对战
- 本地双人对战
- 简单 / 普通 / 困难三档机器棋手
- 悔棋、重新开局、玩法说明
- 泥土地棋盘与木桩 / 石子棋子视觉

## 测试

```bash
npm test
```

当前测试覆盖规则、AI、游戏状态、UI 坐标与本地文件打开兼容性。
